## About me

I'm **Lorenzo Malanotte**, a second-year **Computer Engineering** student at **Politecnico di Torino**.
I like building software that people actually use: together with a friend I developed
[**PhysicsEase**](https://github.com/Lore-byte/PhysicsEaseRelease), an open-source Flutter app for studying physics,
now available on **Google Play** and the **App Store**. Through **MalaTech Software Solutions** I build management
and point-of-sale software, and in my spare time I explore GPU computing with CUDA, computer vision and neural networks
(you can find a few of these experiments in my public repositories).
